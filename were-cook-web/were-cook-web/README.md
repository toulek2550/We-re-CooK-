# We're CooK? — วิธีรันและเอาขึ้นเว็บ

## โครงสร้าง
- `public/index.html` — ตัวเกมทั้งหมด (ภาพ, ล็อบบี้, ห้องรอ, ฉากโต๊ะ) ไฟล์เดียว ไม่ต้อง build
- `server.js` — เซิร์ฟเวอร์ Node.js + Socket.IO ทำหน้าที่เสิร์ฟหน้าเว็บ และส่งข้อมูลล็อบบี้/ห้องแบบเรียลไทม์
- ตัวเกมตรวจเองว่ารันอยู่ที่ไหน: ถ้าเปิดผ่านเซิร์ฟเวอร์นี้จะใช้ Socket.IO อัตโนมัติ ถ้าเปิดไฟล์ตรง ๆ จะเป็นโหมดออฟไลน์มีบอท

## รันในเครื่อง
1. ติดตั้ง Node.js 18 ขึ้นไป (nodejs.org)
2. เปิด terminal ในโฟลเดอร์นี้ แล้วสั่ง
   ```
   npm install
   npm start
   ```
3. เปิด http://localhost:3000 สองแท็บ แท็บหนึ่งสร้างห้อง อีกแท็บใส่รหัสเข้าห้อง
4. ให้เพื่อนในวง Wi-Fi เดียวกันเล่น: เปิด http://<IP เครื่องคุณ>:3000

## เอาขึ้นเว็บจริง (ฟรี) ด้วย Render
1. สร้าง repository บน GitHub แล้วอัปโหลดทั้งโฟลเดอร์นี้ขึ้นไป
2. ไปที่ render.com → New → Web Service → เลือก repo นั้น
3. ตั้งค่า
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
4. กด Deploy รอสักพักจะได้ลิงก์ เช่น `https://were-cook.onrender.com` ส่งลิงก์นี้ให้เพื่อนเล่นได้เลย

หมายเหตุ: แผนฟรีของ Render จะหลับเมื่อไม่มีคนเข้าประมาณ 15 นาที คนแรกที่เข้าอาจต้องรอ 30–60 วินาที

## ทางเลือกอื่น
- **Railway** (railway.app): New Project → Deploy from GitHub → ระบบตั้ง `npm start` ให้เอง
- **Fly.io**: เหมาะถ้าต้องการให้เซิร์ฟเวอร์ใกล้ไทย (เลือก region `sin` สิงคโปร์)
- ห้ามใช้โฮสต์แบบ static อย่างเดียว (GitHub Pages, Netlify แบบปกติ) ถ้าต้องการเล่นหลายคน เพราะต้องมีเซิร์ฟเวอร์ Socket.IO ทำงานตลอด

## รันแบบไม่ต้อง npm install
ถ้าเครื่องติดตั้งแพ็กเกจไม่ได้ (เน็ตโรงเรียน/องค์กรบล็อก) ใช้ `node tools/dev-server-nodeps.js` แทน `npm start`
ตัวนี้โหลด `server.js` ตัวจริง แต่ใช้ช่องทางสื่อสารแบบง่าย (SSE) แทน Socket.IO เล่นหลายเครื่องใน LAN เดียวกันได้ เหมาะกับทดสอบ (ขึ้นเว็บจริงยังใช้ `npm start`)

## ระบบรสชาติและการคิดคะแนน (อัปเดต)
โค้ดส่วนนี้อยู่ที่ `public/shared/engine.js` ไฟล์เดียว ใช้ทั้งในเบราว์เซอร์และบนเซิร์ฟเวอร์ (เหมือนกันทุกบรรทัด)

**1. Recipe & Taste Engine**
- วัตถุดิบทุกอย่างมี "ปริมาณ" ให้เลือก (เช่น หมู 100/150/200 g, พริก 1–5 เม็ด) และมีค่ารส 5 ด้าน: หวาน เค็ม เปรี้ยว เผ็ด อูมามิ (0–100)
- รสของจาน = รวมรสของทุกอย่างบนจาน (ตามปริมาณ) + เครื่องปรุงที่เทลงไป
- รสเป้าหมายของแต่ละเมนู = รสของเมนูนั้นเมื่อทำตามสูตรเป๊ะ ๆ
- ความตรงของรส = 100 − (ค่าต่างเฉลี่ย 5 ด้าน × 2)

**2. Cooking Mini-games** — หั่น ตำ ผัด ทอด ต้ม อบ + ใหม่: ย่าง (พลิก 2 ด้าน), นึ่ง (เติมน้ำ/เปิดฝา), ตำส้มตำ (ตำ/คลุก ตามจังหวะ), ปรุงรส (กดค้างที่ขวด)

**3. Order & Scoring (100 คะแนนต่อจาน)**
- สูตร 40 = ส่วนประกอบถูก 28 + ปริมาณถูก 8 + จัดจานถูกลำดับ 4
- ฝีมือ 25 = คุณภาพเฉลี่ยจากมินิเกม
- รสชาติ 20 = ความตรงของรส
- เวลา 15 = เวลาที่เหลือของออร์เดอร์
- แล้วคูณตามความยาก: 1 ดาว ×0.8, 2 ดาว ×1, 3 ดาว ×1.25

**เซิร์ฟเวอร์เป็นกรรมการ:** ผู้เล่นส่งแค่ "จานที่ทำ" ไป เซิร์ฟเวอร์เป็นคนถือออร์เดอร์ เวลา และคิดคะแนนเอง
ตรวจว่าวัตถุดิบ/ขั้นตอน/ปริมาณมีอยู่จริง จำกัดการส่งไม่เกิน 8 ครั้งต่อวินาที และผู้เล่นแก้คะแนนของตัวเองไม่ได้
(ถ้าเปิดไฟล์ตรง ๆ แบบออฟไลน์ เกมจะใช้โค้ดกรรมการชุดเดียวกันในเบราว์เซอร์แทน)

## ความยากที่ค่อย ๆ เพิ่ม + โหมดทีม 2v2 (อัปเดต)
**ช่วงของรอบ (Stages)** — ครัวค่อย ๆ เปิด ตั้งค่าได้ที่ `STAGES` ใน `public/shared/engine.js`
1. เปิดร้าน (0%): เขียง กระทะ หม้อทอด · เมนูง่าย
2. ลูกค้าเริ่มเยอะ (25%): + หม้อต้ม เตาอบ ครก · วัตถุดิบเพิ่ม
3. ครัวไทยเต็มรูปแบบ (50%): + เตาถ่าน ซึ้งนึ่ง
4. Rush Hour (78%): ออร์เดอร์เวลาสั้นลง 30% แต่คะแนน ×1.5
เมนูที่ออกมาจะเลือกเฉพาะเมนูที่ทำได้ด้วยเครื่องครัวที่เปิดแล้ว · เซิร์ฟเวอร์ไม่รับจานที่ใช้เครื่องครัวที่ยังไม่เปิด

**ทีมละ 2 คน (2v2 หรือ 2v2v2)** — หัวห้องเลือกโหมด "ทีมละ 2 คน" ต้องมี 4 คน (2v2) หรือ 6 คน (2v2v2) เพิ่มบอทได้ · ที่นั่ง 1–2 = ทีมแดง, 3–4 = ทีมฟ้า, 5–6 = ทีมเขียว
- แต่ละคนได้ตู้วัตถุดิบคนละครึ่ง (สุ่มตามรอบ) ของที่เป็นของเพื่อนจะขึ้นป้าย "เพื่อน"
- ส่งของให้เพื่อนร่วมทีมเท่านั้น: ลากไปที่ช่อง "ส่งให้…" หรือกด P · ของจากเพื่อนเข้า "ถาดรับ"
- แตะของที่เป็นของเพื่อนในตู้ = ขอของ (บอทเพื่อนร่วมทีมจะส่งให้เอง)
- ออร์เดอร์และคะแนนเป็นของทีม · เซิร์ฟเวอร์จดว่าใครได้ของอะไรมาจากเพื่อน ใช้ของที่ไม่ได้มาจากตู้ตัวเองหรือเพื่อนไม่ได้

## เสียง (ธีม B: ครัวการ์ตูนแบบเกมปาร์ตี้)

- เสียงตอบสนอง: หยิบ/วาง/ส่งของ ส่งอาหารสำเร็จ/ผิด ออร์เดอร์หมดเวลา นับถอยหลัง เตือน 10 วินาทีสุดท้าย จบเกม ประกาศผล
- ปุ่ม "🔊 เสียง" มุมขวาบน: ปรับความดังทั้งหมด / เพลง / เสียงทำอาหาร (จำค่าไว้ในเครื่อง)
- เบราว์เซอร์จะเริ่มเล่นเสียงหลังผู้เล่นคลิกครั้งแรก

## ทัวร์นาเมนต์ (อัปเดต)
- หัวห้องเลือกโหมด "ทัวร์นาเมนต์" ในห้องรอ ต้องมีอย่างน้อย 2 คน (บอทนับด้วย)
- คนตกรอบต่อรอบ: 5 คนขึ้นไปตก 2 คน, 3-4 คนเหลือ 2, 2 คนเหลือ 1 เช่น 6 → 4 → 2 → 1 🏆 (หน้าห้องรอบอกเส้นทางให้)
- รอบที่ 2 = **รอบวัตถุดิบปริศนา**: ได้กล่องเมนู 4 อย่าง + วัตถุดิบหลอก ช่องที่ไม่มีในกล่องจะขึ้น "ไม่มีในกล่อง"
- รอบสุดท้าย (เหลือ 2 คน) = **รอบชิงชนะเลิศ**: มีกรรมการ 1 คนที่ชอบรสแบบหนึ่ง (เช่น ลุงเปรี้ยวชอบเปรี้ยวจี๊ด) และโบนัส **เซ็ตอาหาร** จานหลัก + เครื่องเคียง + ของหวาน = +60
- คนที่ตกรอบจะดูกระดานคะแนนสดของคนที่ยังแข่งอยู่ หัวห้องตกรอบแล้วก็ยังกดเริ่มรอบถัดไปได้
- เซิร์ฟเวอร์ตรวจทุกขั้น: รอบต้องเรียงกัน, คนที่เข้ารอบต้องมาจากรอบก่อน, จำนวนต้องถูก และคนที่ถูกตัดต้องไม่ได้คะแนนสูงกว่าคนที่เข้ารอบ

## กันโกงคะแนนเทคนิค
- การทำอาหารแจ้งเซิร์ฟเวอร์ 2 ครั้ง (เริ่ม/เสร็จ) เซิร์ฟเวอร์จับเวลาเอง ถ้าเร็วกว่าที่ทำได้จริง (`MIN_COOK` เช่น กระทะ 1.8 วินาที) จะไม่รับ
- ของที่ทำสุกแล้วเก็บใน "สมุดบัญชี" ของผู้เล่นบนเซิร์ฟเวอร์ ตอนเสิร์ฟ เซิร์ฟเวอร์ใช้ค่าคุณภาพจากสมุดของตัวเอง ไม่ใช่จากเครื่องผู้เล่น ส่งของที่ไม่ได้ทำจริงจะขึ้น "ยังไม่ได้ทำจริง"
- ส่งต่อให้เพื่อนร่วมทีมก็ย้ายในสมุดด้วย ทิ้งจานก็ลบออกจากสมุด
- ข้อจำกัด: คะแนนมินิเกม (0-100) ยังมาจากเครื่องผู้เล่น เซิร์ฟเวอร์แค่จำกัดช่วงค่าและเวลา

## กด F5 ไม่หาย
- จำตัวผู้เล่น (localStorage) + ห้อง (sessionStorage 30 นาที) + ของในมือ จาน ถาดรับของ และการปรุงรสของรอบนั้น (sessionStorage `wc_bag`)
- ของที่ทำสุกแล้วยังอยู่ในสมุดของเซิร์ฟเวอร์ เวลาที่เหลือมาจากเซิร์ฟเวอร์

## ภาพเบา (เครื่องช้า)
- ปุ่ม "ภาพสวย/ภาพเบา" บนขวา: ภาพเบา = ความละเอียด 1x, ~30 fps, วาดเงาทุก 3 เฟรม (จำค่าไว้ในเครื่องนั้น)
- ถ้าเครื่องเล่นได้ต่ำกว่า ~24 fps ในช่วงแรก เกมจะเปิดภาพเบาให้เองครั้งเดียว

## ทดสอบที่ทำแล้ว
- เล่นออนไลน์ 3 เบราว์เซอร์จริงกับ `server.js`: ห้อง/หัวห้อง/ที่นั่งตรงกันทุกจอ, ออเดอร์เดียวกันจากเซิร์ฟเวอร์, ทำอาหาร → เซิร์ฟเวอร์รับ, F5 แล้วของในมือ+จานกลับมา, ทัวร์นาเมนต์ 3 คน 2 รอบจนได้แชมป์
- ออฟไลน์ (บอท): ทัวร์นาเมนต์ 5 คน 3 รอบ ทั้งแบบชนะและแบบตกรอบแล้วดูเพื่อน

## หน้าเล่นแบบใหม่ (ตามคอมเมนต์ผู้เล่น)
- หน้าเดียว 3 คอลัมน์: ตู้วัตถุดิบ (ซ้าย) · จาน (กลาง) · เครื่องครัว (ขวา) ไม่ต้องสลับหน้า "ครัว/จาน" แล้ว ใช้ความกว้างจอเต็ม
- ตู้วัตถุดิบ: ของที่ออเดอร์ที่เลือกต้องใช้มีกรอบสีส้ม, ช่องค้นหา, ปุ่มกระโดดไปหมวด
- แตะเครื่องครัวที่เปิดอยู่ซ้ำ (หรือกดเลขเดิม) = กลับไปหน้าจาน
- วิธีทำเมนูตัวใหญ่ขึ้น (ไอคอน 40px, ตัวหนา)
- ปรุงรสแบบใหม่: แถบสีเขียว = รสที่ลูกค้าต้องการ, ป้าย ขาด/พอดี/เกิน, ขวดบอกว่าเพิ่มรสอะไร, ป้าย "แนะนำ" ที่ขวดที่ช่วยมากที่สุด, ปุ่ม − เอาออก; บนมือถือเปิดเต็มจอ
- ไอคอนเครื่องครัว 3D ใหม่ (`tool:*` ใน icons.webp, สร้างด้วย `python3 tools/bake_icons.py` แล้ว `python3 tools/make_offline.py`)

## ทำให้สนุกขึ้น (แนว Family Style)
- **ปรุงรสแบบง่าย:** โชว์เฉพาะขวดที่จานนี้ต้องใช้ (ตามสูตร + คำขอลูกค้า) กดค้างที่ขวดให้น้ำถึงขีดเขียว ครบทุกขวดแล้วปิดเอง จานที่รสดีอยู่แล้วไม่ต้องปรุง ระบบรส 5 มิติยังคิดคะแนนอยู่หลังบ้าน (`idealSeason` ใน engine.js)
- **มินิเกมเร็วขึ้นราว 2 เท่า** (หั่น 2 ครั้ง, ตำส้มตำ 5 จังหวะ ฯลฯ) และเซิร์ฟเวอร์ลด `MIN_COOK` ตาม
- **ความยากค่อย ๆ เพิ่ม:** ออร์เดอร์ค้างพร้อมกัน 2 → 3 → 4 ใบ, 5 ช่วง (เปิดร้าน 0% · ลูกค้าเริ่มเยอะ 18% · ครัวไทยเต็มรูปแบบ 40% · ร้านแน่น 60% · Rush 80%), เวลารอสั้นลง (70/90/110 วิ)
- **คอมโบ:** ส่งจานดี (ครบสูตร ≥ 55 คะแนน) ติดกันภายใน 25 วิ ได้คะแนน ×1.1, ×1.2 … สูงสุด ×1.5
- **ออร์เดอร์ทอง 🥇:** ตั้งแต่ช่วง 2 ทุก ~40 วิ จานเดียวกันโผล่ในครัวทุกคน ใครเสิร์ฟก่อนได้ +80 ของคนอื่นหายทันที (ออฟไลน์ บอทก็แย่งได้)
- **การ์ดแกล้ง:** คอมโบครบ 3 ได้การ์ด 1 ใบ (กดปุ่มบนแถบด้านบน หรือกด C) ใช้กับคนที่นำอยู่: 🔌 ไฟดับ 6 วิ · 🌶️ ควันพริกบังจอ 5 วิ (ถูจอให้หายเร็วขึ้น) · 🍽️ จานสกปรก +2 ใบ — เซิร์ฟเวอร์เป็นคนเลือกเป้าและใส่ผล (`game:prank`)
- **ส่งจานแล้วสะใจขึ้น:** หน้าลูกค้า 😋/🙂/😐, ตัวเลขคะแนนใหญ่, เหรียญบินเข้าคะแนน, ป้ายคอมโบ แตะเพื่อดูคะแนนละเอียดแบบเดิม

## เล่นง่ายสำหรับมือใหม่ (อัปเดต)
- **ความยาก 3 ระดับ** (หัวห้องเลือกในห้องรอ, ค่าเริ่มต้น = ง่าย)
  - 😊 ง่าย: 9 เมนูสั้น (`EASY_MENUS`), ครัวเปิดครบตั้งแต่แรก, ออร์เดอร์ 2→3 ใบ, เวลารอ ×1.5, ไม่ต้องล้างจาน, ไม่คิดปริมาณ/ลำดับจัดจาน, ไม่มีคำขอพิเศษ/การ์ดแกล้ง, ตู้โชว์เฉพาะของที่ออร์เดอร์ใช้, บอทช้าลง
  - 🙂 ปกติ: ครบทุกระบบ
  - 🔥 เชฟ: เวลารอ ×0.8, ออร์เดอร์ +1 ใบ
- **แตะขั้นในวิธีทำ = หยิบของ** แล้วเปิดเครื่องครัวที่ต้องใช้ให้เอง; ถือของอยู่แล้วแตะอีกครั้ง = ไปขั้นต่อไป/วางลงจาน; ขั้นที่ต้องทำต่อมีป้าย 👉 ทำต่อ
- **🎓 ฝึกทำจานแรก** (ปุ่มในล็อบบี้): ครัวส่วนตัว ทำฮอทดอก 1 จาน มีไฟส่องบอกว่าต้องแตะตรงไหน ข้ามได้
- **ดาวเป้าหมาย**: แถบด้านบนมี ★ 3 ขั้น (`starGoals`), จบรอบแสดงดาวที่ได้; ส่งจานแต่ละจานก็ได้ดาว 1–3
- บิลมีรูปวัตถุดิบเล็ก ๆ

## 🛒 ตลาดแย่งกัน (ตัวเลือกในห้องรอ)
- ของแห้ง/ซอส (ข้าว แป้ง ขนมปัง ซอส เนย) อยู่ในตู้ตลอด ส่วนเนื้อ ผัก นม มาบนสายพานกลางทีละชิ้น (ทุก ~1.7 วิ อยู่ได้ 12 วิ)
- ทุกคนเห็นสายพานเดียวกัน ใครแตะก่อนได้ (เซิร์ฟเวอร์ตัดสิน `game:grab`) ของที่ออร์เดอร์เราใช้มีกรอบส้ม
- ตะกร้าเก็บได้ 6 ชิ้น, ทิ้ง/เทจาน = ของหายไปจริง
- ใช้ได้ในความยากปกติ/เชฟ โหมดเดี่ยวและทัวร์นาเมนต์ (ไม่ใช้กับโหมดทีมและรอบกล่องปริศนา); ออฟไลน์บอทก็แย่งของ

## อีโมตด่วน
- ปุ่ม 😀 บนแถบด้านบน ส่งข้อความสั้น (👍 เยี่ยม! / 😂 555 / 🔥 รีบ! ...) โผล่ข้างชื่อเราบนกระดานคะแนนของทุกคน 3 วิ

## 🤝 ร้านเดียวกัน — โหมดหลัก แบบ Family Style
ค่าเริ่มต้นของห้องใหม่ · ทำตามกลไกของ Family Style จริง: ทุกคนเป็นสเตชันของตัวเอง ของไม่เหมือนกัน ต้องคุยกันและส่งต่อ
- **ที่นั่งเป็นวง:** ส่งของได้แค่คนทางซ้าย/ขวา (ปุ่ม ⬅ ➡ ใต้จาน, คีย์ Q / E, หรือลากของไปใส่ปุ่ม) ของที่ได้รับเข้า "ถาดรับ"
- **วัตถุดิบแบ่งกัน:** แต่ละคนมีวัตถุดิบคนละชุด ของคนอื่นในตู้มีรูปเจ้าของ + ลูกศรบอกทาง แตะ = ตะโกนขอ (📣) เจ้าของได้รับแจ้ง แตะของในตู้เพื่อส่งกลับทางผู้ขอได้เลย
- **เครื่องครัวแบ่งกัน:** แต่ละคนมีเครื่องครัวคนละอย่าง (แจกแบบให้ทุกคนมีของที่เปิดช่วงแรก; 4 คนขึ้นไปเปิดครบทุกเครื่องตั้งแต่ต้น) เครื่องของเพื่อนขึ้นชื่อเจ้าของ แตะแล้วเกมบอกว่าต้องส่งไปทางไหน → ส่งของดิบไปให้เพื่อนทำ แล้วเพื่อนส่งของสุกกลับมา
- **จานของตัวเอง:** จัดจานบนจอตัวเองแล้วส่ง ออร์เดอร์และคะแนนเป็นของร้าน ดาวคิดตามจำนวนเชฟ เวลารอนานขึ้น 25% เมื่อเล่นหลายคน
- **👑 Master Chef:** คนที่ทำคะแนนให้ร้านมากสุด (โชว์มงกุฎบนแถบคะแนนและหน้าผล)
- **บอท = เพื่อนร่วมสเตชัน:** ส่งของที่ออร์เดอร์ต้องใช้และมีแต่บอทมาให้ (ไม่ส่งท่วม), รับของที่เราส่งไปแล้วทำด้วยเครื่องของตัวเองแล้วส่งกลับ, ส่งของต่อรอบวง, ตอบเมื่อเราขอ, ว่างแล้วทำจานเสิร์ฟเอง
- **การ์ด (คอมโบ 3):** ในโหมดนี้เป็นการ์ดช่วยทีม ⏰ ลูกค้าใจเย็น (+20 วิทุกออร์เดอร์) · 💰 ทิปพิเศษ (3 จานถัดไป ×1.5) · 🧽 ล้างจานหมด
- **ร้านคู่แข่ง 😈:** ตั้งแต่ 30% ของรอบ ทุก 40–55 วิ แกล้งเชฟ 1 คน (ไฟดับ / ควันพริก / จานกองท่วม) — ไม่มีในความยากง่าย
- **🛒 ตลาดแย่งกัน** ใช้กับโหมดนี้ได้: ของแห้ง/ซอสแบ่งกันในวง ส่วนเนื้อ/ผัก/นม มาบนสายพาน ใครคว้าก่อนได้แล้วส่งต่อในวงได้
- โค้ด: engine `createMatch({mode:'coop'})` (`ringPantry`, `ringTools`, `ringOf`, `toward`, `M.pass(..., dir)`, `M.ask` หาเจ้าของ, บอท co-op + `nextChaos` ใน `M.tick`, `CO_CARDS`, `p.pts`), server `game:pass` รับ `dir`, client `renderRing`, `passItem(it,take,dir)`, `toolMine/toolOwner/ingOwner/sideOf`, `awayMsg`

## 📅 โหมดด่าน/วัน (ค่าเริ่มต้นของ "ร้านเดียวกัน")
- 12 วัน 3 ครัว: 🏠 ครัวบ้านป้าแดง (วัน 1–4) · 🍔 ร้านอาหารฝรั่ง (5–8) · 🌶 ครัวไทยเยาวราช (9–12)
- รอบละ 75 วิ (วันสุดท้าย 120 วิ) ได้ ★1–3 ตามคะแนน ต้องได้อย่างน้อย ★1 เพื่อปลดล็อกวันถัดไป (เก็บในเครื่อง)
- แต่ละวันเปิดระบบทีละอย่าง (เหตุการณ์ประจำวัน): แบ่งของส่งซ้าย/ขวา → ล้างจาน → ปรุงรส → ออร์เดอร์ทอง → ตลาด → ร้านคู่แข่งป่วน → การ์ดช่วยทีม วันแรก ๆ จึงเล่นง่าย ไม่มีทุกอย่างพร้อมกัน
- ในโหมดวัน การทำอาหารเป็นแบบ "กดค้างจนเขียวแล้วปล่อย" ทุกสถานี (มินิเกมเต็มยังอยู่ในโหมด "⏱ เล่นยาว")
- แต่ละครัวมีสีธีมของตัวเอง + การ์ดแนะนำวันก่อนเริ่ม (เมนู ระบบที่เปิด เกณฑ์ดาว)
- เห็นว่าเพื่อนถือของอะไรอยู่ + ปุ่มอีโมต/ตะโกนเรียกกัน
- จบวันมีปุ่ม "วันถัดไป ▶" หรือ "เล่นวันนี้อีกรอบ"

## นับวัตถุดิบเป็น "ชิ้น" อย่างเดียว
- ตัดเรื่องกรัม/จำนวนชิ้นออกทั้งหมด วัตถุดิบ 1 อย่าง = 1 ชิ้น ไม่ต้องกด +/− อีก
- คะแนน "ปริมาณ" รวมเข้าไปในคะแนนส่วนประกอบ (ใส่ของครบ = ได้เต็ม)

## เล่นต่อเนื่องแบบ Family Style + แถบบอกทีละขั้น
- ไม่ต้องเลือกวันแล้ว: กด "เปิดร้าน" → เล่นวันปัจจุบันเลย ได้ ★ อย่างน้อย 1 ดวง = ไปวันถัดไปทันที ไม่ได้ดาว = ร้านปิด เริ่มใหม่วันที่ 1 (เก็บสถิติ "ไกลสุด") ผ่านวัน 12 = ชนะทั้งร้าน
- ห้องรอเหลือแค่: การ์ดวันนี้ (ครัว · วันที่ n/12 · จุดความคืบหน้า) + เพิ่มบอท + เริ่มเกม ส่วนโหมดอื่น/เล่นยาว/ความยาก/ตลาด/ขนาดห้อง/เวลา ย้ายไปไว้ใน "⚙️ โหมดอื่น / ตั้งค่าเพิ่ม"
- หน้าแรกเขียนใหม่ให้ตรงกับเกม (ช่วยกัน ไม่ใช่แข่ง) + การ์ด 3 ขั้นวิธีเล่น · เอาตัวเลือกขนาดห้อง/เวลาออกจากหน้าแรก
- ในเกมมี "แถบบอกทีละขั้น" บรรทัดเดียวบนจาน บอกว่าตอนนี้ต้องทำอะไร และสิ่งที่ต้องกดจะมีกรอบเหลืองกระพริบ (หยิบ → ทำ → วาง → ปรุง → ส่ง, ส่งของให้เพื่อนที่มีเครื่องครัว, เพื่อนขอของ, ล้างจาน)
- เอาคำอธิบายเล็ก ๆ ที่ซ้ำกันออก และเอาป้ายปุ่มคีย์บอร์ด (Space, Enter, Q/E, เลข 1–6, S) ออกทั้งหมด (ปุ่มคีย์บอร์ดยังใช้ได้เหมือนเดิม)

## กติกาวันแบบ Family Style (ไม่มีดาวแล้ว)
- แต่ละวันต้องส่งอาหารให้ครบตามจำนวน (วันแรก 3 จาน → วันสุดท้าย 10 จาน, คนเยอะขึ้นต้องส่งเพิ่ม) ไม่มีนาฬิกาจับเวลาทั้งรอบ
- ทุกออร์เดอร์มีหลอดความอดทนของตัวเอง หลอดหมด = ลูกค้าโกรธเดินออก เสีย ❤ 1 ดวง (มี 3 ดวงต่อวัน) หมด 3 ดวง = ร้านปิด เริ่มใหม่วันที่ 1
- ส่งครบ = ผ่าน → ขึ้นหน้าโหลด "กำลังเปิดร้าน…" (บอกเมนูใหม่ เครื่องครัวใหม่ ระบบใหม่ จำนวนจานที่ต้องส่ง) แล้วเข้าวันต่อไปเองใน 5 วิ ไม่ต้องกดอะไร (หัวห้องกด "พักก่อน" ได้)
- ยิ่งวันหลัง ๆ ยิ่งยาก: ต้องส่งจานมากขึ้น ออร์เดอร์มาพร้อมกันมากขึ้น ลูกค้าใจร้อนขึ้น และเครื่องครัว/สเตชั่นที่แต่ละคนดูแลเพิ่มขึ้น (การ์ดเปิดวันบอกว่า "วันนี้คุณดูแล …")
- ด้านบนจอแสดง ❤️❤️❤️ กับ "ส่งแล้ว x/y จาน" แทนนาฬิกา · โหมด "เล่นยาว" ยังเป็นแบบจับเวลา + ดาวเหมือนเดิม

## หลอดคะแนนร้าน + การ์ดวิธีทำ + ตู้ของตัวเอง (แบบ Family Style)
- แทนหัวใจด้วย "⭐ คะแนนร้าน" (0–100 เริ่ม 60) ลดลงเรื่อย ๆ ตลอดเวลา (วัน 1 = 0.5/วิ → วัน 12 = 1/วิ) · ส่งอาหาร = เติม +10…+35 ตามคุณภาพ · ออร์เดอร์หมดเวลา = ลดฮวบ −25 · หมดหลอด = ร้านปิด เริ่มใหม่วันที่ 1 · ส่งครบจำนวน = ผ่านวัน
- หลอดเปลี่ยนสี เขียว/เหลือง/แดง กะพริบตอนใกล้หมด มีตัวเลข +/− เด้งขึ้น
- วิธีทำเป็นการ์ดรูป: รูปวัตถุดิบใหญ่ + ป้ายวงกลมเล็กบอกเครื่องครัวที่ต้องผ่าน (เช่น มีด/หม้อทอด) + ชื่อสุดท้าย · ของที่อยู่ที่เพื่อนมีป้ายชื่อเพื่อนด้านบน
- ช่องวัตถุดิบ: แสดงเฉพาะ "ของของคุณ" เป็นลังใหญ่ ไม่มีช่องค้นหา/หมวด · ของที่ไม่มีอยู่ที่เพื่อน แตะการ์ดวิธีทำเพื่อขอ

## โหมดวัน: ยากขึ้นนิดนึง
- เอาตัวช่วยสีส้มออก: กรอบส้ม/ป้าย "👉 ทำต่อ" บนการ์ดวิธีทำ และกรอบส้ม/จุดส้มบนลังวัตถุดิบที่ต้องใช้
- กรอบเหลืองกระพริบชี้ปุ่ม มีแค่วันที่ 1–3 (ช่วงหัดเล่น) หลังจากนั้นเหลือแค่ข้อความบอกขั้นด้านบน
- หลอดคะแนนร้านลดเร็วขึ้น ~20% (วัน 1 = 0.6/วิ → วัน 12 = 1.2/วิ) และลูกค้ารอได้สั้นลงเล็กน้อย

## โหมด "ร้านเดียวกัน" แบบ Family Style (โต๊ะอิสระ)
- หน้าเล่นใหม่ทั้งหมด: โต๊ะสีเขียว 1 ตัว มีเครื่องครัวของคุณ + จาน 1 ใบ ทุกชิ้นเป็นภาพ 3D ไม่มีกรอบ ขนาดต่างกันตามของจริง (พริกเล็ก ปลา/พิซซ่าใหญ่ เตาอบใหญ่ ครกเล็ก)
- วัตถุดิบ "หล่น" มาบนโต๊ะเรื่อย ๆ (เฉพาะของที่คุณมี) จนรก ของที่ไม่ใช้ลากไปขอบซ้าย/ขวาส่งให้เพื่อน หรือถังขยะ · ของจากเพื่อนจะไหลเข้ามาจากขอบฝั่งนั้น
- ลากทุกอย่างได้: ของ จาน และเครื่องครัว ย้ายไปวางตรงไหนก็ได้ · หรือแตะของ แล้วแตะที่ที่จะวาง
- ทำอาหาร: ลากของไปเครื่องครัว แล้วแตะ 6 ครั้ง (วงกลมจับเวลาแบบพาย) · วางบนจาน · ลากจานไปที่ออร์เดอร์เพื่อเสิร์ฟ (ต้องครบพอดี)
- ออร์เดอร์มีวงกลมเวลา · แตะไอคอนที่มี 📣 เพื่อขอของจากเพื่อน
- การ์ดรอบแบบ Family Style: "รอบที่ N:" แสดงสูตรใหม่ วัตถุดิบ ➜ เครื่องครัว ➜ ของที่ได้ + วงกลมนับถอยหลัง · จบรอบ "รอบที่ N ผ่าน!" แล้วเข้ารอบต่อไปเองเลย (ไม่มีปุ่มพัก)
- ไม่บันทึกวันแล้ว: ออกจากเกม/ออกจากห้อง/รีเฟรช = เริ่มใหม่วันที่ 1
- ตัดระบบเสริมออกจากโหมดนี้ (ล้างจาน ปรุงรส ออร์เดอร์ทอง ตลาด ร้านคู่แข่ง การ์ด) · แบ่งวัตถุดิบเฉพาะของที่ใช้ในวันนั้น
- โหมดอื่น: ตัวเลือก "ตู้ไม่จำกัด" ออกแล้ว ใช้ "ตลาดแย่งกัน" อย่างเดียว · ไอคอนเครื่องครัวในวิธีทำใช้ภาพเดียวกับปุ่มเครื่องครัว (หม้อทอดตรงกันแล้ว)

## ร้านเดียวกัน = เล่นยาวต่อเนื่อง (ไม่แบ่งวันแล้ว)
- กดเริ่มเกมแล้วเล่นไปเรื่อย ๆ ในเกมเดียว: ส่งครบจำนวนของรอบ → ขึ้นการ์ด "รอบที่ N ผ่าน!" แล้ว "รอบที่ N+1:" ทับบนโต๊ะ (ออร์เดอร์/หลอดหยุดชั่วคราว ~5 วิ) แล้วเล่นต่อบนโต๊ะเดิม ของบนโต๊ะยังอยู่
- ทุกรอบเพิ่มเมนู/เครื่องครัวใหม่ (เครื่องครัวใหม่จะไปวางในที่ว่างบนโต๊ะ) แจกของ/เครื่องครัวให้แต่ละคนใหม่ ยิ่งเล่นยิ่งยาก · ผ่านรอบได้ ⭐ +15
- จบเกมเมื่อหลอดคะแนนร้านหมด (บอกว่าไปถึงรอบไหน ส่งรวมกี่จาน) หรือผ่านครบ 12 รอบ
- ห้องรอ: เอาตัวเลือก "เล่นเป็นวัน/เล่นยาว" ออก · การ์ดอธิบายอ่านง่ายในโหมดมืดแล้ว

## ปรับตามคลิป gameplay Family Style
- มือถือ: ถ้าถือแนวตั้งจะขึ้นชวนให้หมุนเป็นแนวนอน (ปุ่ม "เต็มจอ + แนวนอน" หรือเล่นแนวตั้งต่อ) · แนวนอนจอเตี้ยจัดหน้าใหม่ให้โต๊ะเต็มจอ ซ่อนหัวเว็บ
- ออร์เดอร์เป็นการ์ดขาวห้อยจากขอบบนของโต๊ะ (มีรอยบากด้านล่าง) แสดงรูปของที่ทำเสร็จแล้ว + ป้ายเครื่องครัว · ขอบการ์ดเปลี่ยนสี ม่วง → ชมพู → แดง (สั่น) ตามเวลาที่เหลือ
- หลอดคะแนนร้านย้ายไปอยู่ล่างกลางโต๊ะแบบ SCORE ในเกม
- จบเกม: การ์ด Master Chef + สถิติ คุณ (ส่ง/คะแนน/ส่งต่อ/ทิ้ง) · ทีม (ส่ง/คะแนน/ลูกค้าเดินออก) · ร้าน (เชฟ/ถึงรอบ/เวลา)
- หน้าเล่นแบบเก่า (โหมดแข่ง/ทีม/ทัวร์ + ฝึกเล่น): แตะขั้นในวิธีทำไม่หยิบของให้แล้ว ไม่มีกรอบส้ม "ทำต่อ" · ผู้เล่นต้องหาของในตู้เอง → แตะเครื่องครัว → แตะจานเพื่อวาง (แถบบอกขั้นชี้ไปที่ตู้/เครื่องครัว/จานแทน)

## เมนูเป็นการ์ดซ้อน (แบบ Family Style) — ทุกโหมด
- ร้านเดียวกัน: แต่ละออร์เดอร์เป็นปึกการ์ด ใบหน้าแสดงแค่ "ชิ้นถัดไป" (รูปของที่ทำเสร็จ + เครื่องครัวที่ต้องใช้) ใบหลังโผล่ด้านข้างบอกว่าเหลืออีกกี่ขั้น · วางถูกชิ้นลงจาน → การ์ดพลิกไปใบถัดไป · ครบทุกใบ → การ์ดเขียว "✓ ลากจานมาเสิร์ฟ" แล้วลากจานไปที่การ์ด
- วางของที่ไม่มีออร์เดอร์ไหนใช้ (หรือยังไม่ได้ทำ เช่นกุ้งดิบ) ลงจาน → จานขึ้น ✕ และไม่รับ
- โหมดอื่น (แข่ง/ทีม/ทัวร์/ฝึกเล่น): วิธีทำเหลือการ์ดใบเดียวของขั้นถัดไป (มีใบหลังซ้อน + "ขั้น 2/3") · ไม่มีกรอบส้มในตู้วัตถุดิบ และแถบบอกขั้นไม่ชี้ของในตู้ ผู้เล่นต้องหาเอง

## ร้านเดียวกัน: ทีละออร์เดอร์
- บนโต๊ะเห็นออร์เดอร์ทีละ 1 ปึก (ปึกที่จานกำลังทำอยู่ หรือปึกที่แจกให้คุณ) ที่เหลือรวมเป็นป้าย "อีก N ออร์เดอร์"
- จำนวนออร์เดอร์พร้อมกัน = จำนวนเชฟในร้าน (คนละ 1 ใบ) · เล่นคนเดียว = ทีละ 1 ออร์เดอร์เลย

## ส่งของแบบ Family Style (ไม่มีแผงสีฟ้า)
- เอาแผงสีฟ้าซ้าย/ขวาออก โต๊ะเต็มความกว้าง · ขอบซ้าย/ขวาของโต๊ะจะสว่างขึ้นพร้อมลูกศร ⇦ ⇨ + รูป/ชื่อเพื่อน เฉพาะตอนกำลังลากของ
- ส่งได้ 2 แบบ: ลากไปปล่อยที่ขอบ หรือ "โยน" (ปัดเร็ว ๆ ไปทางซ้าย/ขวา)
- เอฟเฟกต์: ของพุ่งออกขอบพร้อมเงาจาง ๆ ตามหลัง + ประกายดาวที่ขอบโต๊ะ · ของที่เพื่อนส่งมาไหลเข้าจากขอบพร้อมประกายดาว
- คำอธิบายวิธีเล่นย้ายไปอยู่ในการ์ด "รอบที่ 1:" ตอนเริ่ม (รอบ 1–3 แสดง ~7 วิ แตะเพื่อปิด) ไม่มีแถบข้อความระหว่างเล่นแล้ว

## โต๊ะเต็มจอ + ของเป็นของแข็ง
- โหมดร้านเดียวกัน: โต๊ะเต็มหน้าจอ (ซ่อนหัวเว็บ) ป้ายรอบ/จำนวนจาน/ปุ่มออก ลอยอยู่มุมบน · ของ/เครื่องครัว/จานขยายตามขนาดจอ
- ขอบส่งของแสดงแค่ลูกศร ⇦ ⇨ ตอนลาก (ไม่มีรูป/ชื่อเพื่อน)
- ของบนโต๊ะเป็นของแข็ง: อยู่ใกล้กันจะเบียดกัน · ลากชนแรง ๆ ของอีกชิ้นกระเด็นไถลไป แล้วค่อย ๆ หยุด · ชนเครื่องครัว/จาน/ขอบโต๊ะแล้วเด้งกลับ
- ของที่กระเด็นจากการชนส่งให้เพื่อนไม่ได้ (ชนขอบแล้วเด้งกลับ) · ส่งได้เฉพาะตอนเราลากไปปล่อยที่ขอบ หรือโยนแล้วปล่อยมือใกล้ขอบฝั่งนั้น
- ลากของบนโต๊ะแล้วปล่อยกลางโต๊ะ ของจะไถลต่อตามแรงมือ

## ร้านเดียวกัน: ออร์เดอร์ของใครของมัน (ตาม devlog ของ Family Style)
- ทุกคนมีออร์เดอร์ของตัวเองคนละใบ (ไม่ซ้ำกัน) เห็นแค่การ์ดของตัวเอง เสิร์ฟได้แค่ออร์เดอร์ของตัวเอง
- วัตถุดิบถูกสุ่มแบ่งให้ทุกคนตั้งแต่รอบ 1 (เล่นกับเพื่อน/บอท) และของที่หล่นบนโต๊ะเรามักเป็นของที่ "เพื่อน" ต้องใช้ → ต้องส่งให้กันตลอด
- บอทช่วยส่งของที่เจ้าของออร์เดอร์ต้องใช้ไปหาคนนั้นโดยตรง และเสิร์ฟเฉพาะออร์เดอร์ของบอทเอง
- เอาขวดซอส (มายองเนส มัสตาร์ด ซอสมะเขือเทศ ฯลฯ) ออกจากโหมดนี้ทั้งหมด
- ของ เครื่องครัว จาน ใหญ่ขึ้น มีเงาแบนแบบการ์ตูน สีสดขึ้น · ขนาดปรับตามจอ (มือถือเล็กลง)
- เครื่องครัวกับจานลากย้ายไปวางตรงไหนก็ได้ · ของชนิดเดียวกันหล่นค้างบนโต๊ะได้ไม่เกิน 3 ชิ้น

## ร้านเดียวกัน: ภาพแบนแบบการ์ตูน (Family Style look)
- โหมดนี้ใช้ภาพวาด 2D แบน (เวกเตอร์) แทนภาพ 3D ทั้งของ เครื่องครัว จาน การ์ดออร์เดอร์ และการ์ดรอบ · เงาแบนใต้ชิ้น
- ของที่ทำแล้วเปลี่ยนสีให้เห็นชัด: ทอด/อบ = เหลืองทอง · ผัด/ย่าง = น้ำตาล · ต้ม/นึ่ง = สว่างขึ้น
- ไม่มีป้ายชื่อเครื่องครัว/คำว่า "จาน" บนโต๊ะ · โหมดอื่นยังใช้ภาพ 3D เหมือนเดิม

## ร้านเดียวกัน: เมนูใหม่แบบ Family Style + ชื่อหน้าโหลด
- เมนูชุดใหม่สำหรับโหมดนี้ 26 จาน: จานเล็ก 1–4 ชิ้น ไม่มีซอส เช่น สลัดผักสด มะม่วงหั่น มะเขือเทศชีส เฟรนช์ฟรายส์ กุ้งทอดกับผักสด ไก่ทอด โดนัทไอศกรีม ฮอทดอก ไข่ดาวบนขนมปัง ชีสเบอร์เกอร์ สเต๊กกับเฟรนช์ฟรายส์ แซลมอนอะโวคาโด พิซซ่าชีส ครัวซองต์เนย BLT สปาเกตตีชีส ทาโก้อะโวคาโด ไก่ทอดมันบด ไก่ย่าง หมูปิ้ง กุ้งเผาพริก ต้มยำกุ้ง ส้มตำ ไก่ย่างข้าวเหนียว ข้าวเหนียวมะม่วง ปลานึ่งกระเทียมพริก
- เครื่องครัวเปิดทีละอย่าง: รอบ 1 เขียงอย่างเดียว → 2 หม้อทอด → 4 กระทะ → 6 เตาอบ → 7 หม้อต้ม → 8 ครก → 9 เตาถ่าน → 11 ซึ้งนึ่ง → 12 ทุกอย่าง
- ชื่อรอบใหม่ เช่น "เปิดร้าน: เขียงอย่างเดียว", "หม้อทอดมาแล้ว", "เปิดกระทะ", "เปิดเตาอบ", "ครัวไทย", "งานเลี้ยงใหญ่"
- ชื่อหน้าโหลดแบบ Family Style: จบรอบ "🍽 กำลังเก็บจาน…" · ก่อนเริ่มรอบ "🧽 กำลังเช็ดโต๊ะ…" · ก่อนเข้าเกม "🧺 กำลังเติมของเข้าครัว…" (ชื่อรอบย้ายไปเป็นบรรทัดรองใต้หัวการ์ด)

## ชื่อโหมด
- "ร้านเดียวกัน" เปลี่ยนชื่อเป็น "🍳 ครัวโกลาหล"

## หน้าแรก/ห้องรอ + ล็อกห้อง
- ปุ่มหน้าแรกเปลี่ยนเป็น "🎮 เริ่มเกม (สร้างห้อง)" · คำโปรยและการ์ด 3 ใบอธิบายโหมด: ครัวโกลาหล / ทัวร์นาเมนต์ / ทีม 2 ต่อ 2
- ห้องรอมีการ์ดอธิบายของทุกโหมด (เปลี่ยนตามโหมดที่เลือก) ชื่อปุ่มโหมด: 🍳 ครัวโกลาหล · ⚔️ เดี่ยว · 👥 ทีม 2 ต่อ 2 · 🏆 ทัวร์นาเมนต์
- ปุ่ม "🔒 ล็อกห้อง" (หัวห้อง): ล็อกแล้วห้องหายจากรายการห้องที่เปิดอยู่ และ **เซิร์ฟเวอร์** ปฏิเสธคนใหม่ที่พยายามเข้าด้วยรหัส (`room:locked`) · คนที่อยู่ในห้องแล้ว หรือกด F5 กลับมาด้วย player id เดิม ยังเข้าได้ · แตะอีกครั้งเพื่อเปิด

## ทัวร์นาเมนต์ Thai Kitchen Battle: มีรอบทีม 2v2 (4 หรือ 6 คนเท่านั้น)
- เล่นได้เฉพาะจำนวนคู่ 4 หรือ 6 คน (รวมบอท) · จำนวนคี่ กดเริ่มไม่ได้ (เซิร์ฟเวอร์ก็ปฏิเสธ)
- 6 คน: รอบคัดเลือก (เหลือ 4) → รอบวัตถุดิบปริศนา (จัดอันดับ ไม่ตัด) → รอบทีม 2v2 (ทีมชนะ 2 คนไปต่อ) → รอบชิง 1v1 เซ็ตเมนู + กรรมการ
- 4 คน: รอบวัตถุดิบปริศนา → รอบทีม 2v2 → รอบชิง
- จับคู่รอบทีมตามอันดับรอบก่อน: อันดับ 1+4 เจอ 2+3 · ส่งของให้คู่ได้เท่านั้น · คะแนนทีม = คะแนนรวม
- เซิร์ฟเวอร์เป็นคนตัดสินทีมที่ชนะ (`tours.win`) และรับเฉพาะคู่นั้นเข้ารอบชิง · ตรวจจำนวนคนที่ผ่านแต่ละรอบตามแผน (`TOUR_PLANS`)

## อัปเดต: จานล็อกเมนู · ปัดจานเสิร์ฟ · กันเกมค้างตอนคนหลุด · แผงกันโกง 🛡️

### ครัวโกลาหล (ให้เหมือน Family Style ขึ้น)
- **จานล็อกกับเมนูเดียว**: ออร์เดอร์ที่ใกล้หมดเวลาที่สุดของเรา ใส่ของผิดเมนูไม่ได้ (เด้ง ✕)
- ส่งแล้วหรือลูกค้าเดินออก → **จานใบใหม่เลื่อนลงมา** พร้อมเมนูถัดไป (ของที่ค้างบนจานหล่นกลับลงโต๊ะ)
- **วงเวลาสีแดงบนจาน** = เวลาของออร์เดอร์ (ใกล้หมดจะเต้น)
- จานครบแล้ว **ปัดจานขึ้น หรือแตะจาน** เพื่อเสิร์ฟ (ลากไปที่การ์ดก็ยังได้)
- ถังขยะ/ลูกศรส่งของ **โผล่เฉพาะตอนถือของ**
- เครื่องครัววางเอียงแบบสุ่ม
- การ์ดจบเกมมี **เกรดการใช้เครื่องครัว A–F** (ทำ/วางจาน/ส่งต่อ เทียบกับ ทิ้ง/ใส่ผิด/ลูกค้าเดินออก)
- แก้บั๊ก: ออร์เดอร์ในโหมดนี้เคยได้รหัสซ้ำกัน (ออร์เดอร์หนึ่งหมดเวลา อีกใบหายไปด้วย) → ตอนนี้รหัสไม่ซ้ำแล้ว

### กันเกมค้างตอนมีคนหลุด
- **หัวห้องหลุด** → คนถัดไปเป็นหัวห้องแทนอัตโนมัติ และรับการตั้งค่าห้องต่อ (โหมด, บอท, ทัวร์นาเมนต์ที่เล่นค้าง)
- **ผู้เล่นหลุดกลางทัวร์นาเมนต์** → ถือว่าตกรอบ เกมเดินต่อได้
  - ถ้าถึงรอบทีมแต่เหลือไม่ครบ 4 คน → รอบนั้นแข่งเดี่ยวแทน
  - คนที่ผ่านรอบแล้วหลุดก่อนเริ่มรอบใหม่ → คนคะแนนถัดไปขึ้นมาแทน
  - เซิร์ฟเวอร์ตรวจกฎเดียวกัน (นับเฉพาะคนที่ยังอยู่ในห้อง)

### 🛡️ แผงกันโกง (ใช้โชว์อาจารย์)
- ปุ่ม 🛡️ มุมซ้ายล่าง (เฉพาะตอนออนไลน์) → เห็นบันทึกการโกงที่เซิร์ฟเวอร์ปฏิเสธ แบบเรียลไทม์ ทุกคนในห้องเห็น
- ปุ่ม **🧪 ทดลองโกง** ยิงคำสั่งปลอม 5 แบบใส่เซิร์ฟเวอร์จริง:
  1. แก้คะแนนตัวเองเป็น 99,999 → ถูกลบทิ้ง
  2. เสิร์ฟจานที่ไม่ได้ทำจริง → ปฏิเสธ
  3. ทำอาหารเสร็จใน 0 วินาที → ปฏิเสธ
  4. ส่งของที่ไม่เคยทำให้เพื่อน → ปฏิเสธ
  5. ยิงคำสั่ง 25 ครั้งรวด → ถูกบล็อก (จำกัด 8 คำสั่ง/วินาที)
- ทุกการปฏิเสธถูกเขียนลง log ของเซิร์ฟเวอร์ด้วย บรรทัดขึ้นต้น `[SECURITY]` (ดูได้ใน Render → Logs)
- ตอนเล่นออนไลน์ เบราว์เซอร์ไม่ส่งคะแนนเองแล้ว เซิร์ฟเวอร์เป็นคนเขียนคะแนนให้ทั้งหมด

## อัปเดต: แก้บั๊กจากการลองเล่นจริง (ครัวโกลาหล)
- **เสิร์ฟซ้ำ/ของผี**: ตอนออนไลน์ ออร์เดอร์ใหม่มาถึงก่อนคำตอบการเสิร์ฟ ทำให้ของในจานหล่นกลับลงโต๊ะทั้งที่เสิร์ฟไปแล้ว (เอาไปใช้ต่อไม่ได้) → แก้แล้ว และกันกดเสิร์ฟซ้ำระหว่างรอเซิร์ฟเวอร์
- **ปัดจานขึ้นแล้วไม่เสิร์ฟ** ถ้าปัดช้า → จานที่ครบแล้ว แค่ลากขึ้นก็เสิร์ฟ (ไม่ต้องเร็ว)
- เครื่องครัวน้อยกว่าจำนวนคน บางคนจะไม่มีเครื่องครัว (ตั้งใจ แบบ Family Style) → ต้องส่งของให้เพื่อนที่มีเครื่องครัวทำ
- **ขึ้นรอบใหม่แล้วของเก่าค้างบนโต๊ะ** ใช้ไม่ได้เพราะตู้วัตถุดิบเปลี่ยน → เช็ดโต๊ะให้ตอนขึ้นรอบใหม่
- **โต๊ะเต็มแล้วของที่ต้องใช้ไม่มาเลย** → ถ้าของชิ้นที่การ์ดเราต้องการไม่มีอยู่เลย จะยังเกิดให้ (เกินได้นิดหน่อย)
- **บอทฉลาดขึ้น**: ช่วยส่งของถี่ขึ้น, ทำขั้นแรกให้ได้ (เช่น หั่นมันฝรั่งก่อนส่ง), และถ้าเราส่งของที่ทำครึ่งทางไปให้ (เช่น มันฝรั่งหั่น) บอทที่มีหม้อทอดจะทอดแล้วส่งคืน
- รูปบนการ์ดออร์เดอร์ (ของหั่น) ไม่ล้นทับชื่อเมนูแล้ว

## อัปเดต: ครัวโกลาหลสุ่มใหม่ทุกเกม (แบบ Family Style) · วัตถุดิบใหม่ · ของไหม้
- **ไม่มีลำดับตายตัวแล้ว**: ทุกเกมสุ่มเส้นทางของตัวเอง (ใช้ gen ของเกมเป็น seed → ทุกจอ + เซิร์ฟเวอร์ได้ชุดเดียวกัน)
  - รอบ 1 เปิดเครื่องครัวสุ่ม 1 อย่าง + เมนูที่ไม่ต้องใช้เครื่องครัว (วางลงจานได้เลย)
  - รอบต่อ ๆ ไปเปิดเครื่องครัวใหม่แบบสุ่ม (อย่างน้อยทุก 2 รอบ) เฉพาะอันที่มีเมนูใช้ได้จริง
  - จานใหญ่ขึ้นตามรอบ: รอบ 1–2 ไม่เกิน 2 ชิ้น · 3–5 ไม่เกิน 3 · 6+ ได้ถึง 4 ชิ้น
  - รอบ 12 "งานเลี้ยงใหญ่" สุ่ม 8 เมนูจากทุกอย่างที่เปิดมา
- **วัตถุดิบใหม่ 7 อย่าง**: แครอท แตงกวา พริกหยวก แอปเปิ้ล กล้วย สตรอว์เบอร์รี เลมอน (วาดใหม่สไตล์เดิม)
- **เมนูใหม่ 13 เมนู** (รวม 39): สตรอว์เบอร์รีสด, กล้วยไอศกรีม, ขนมปังชีส (ไม่ต้องใช้เครื่องครัว) · ผลไม้รวม, แครอทแตงกวาแท่ง, สลัดจานใหญ่ (4 ชิ้น), กล้วยทอด, ไข่ผัดพริกหยวก, แซลมอนเลมอน, ผักย่าง, ไก่ย่างเลมอน, แอปเปิ้ลอบไอศกรีม, แครอทต้มกับขนมปัง
- **🔥 ของไหม้**: กระทะ / หม้อทอด / เตาถ่าน / เตาอบ — ทำเสร็จแล้วต้องรีบเอาออก
  - 3 วินาที: เครื่องครัวเริ่มมีควัน วงเวลาสีแดงนับถอยหลัง
  - 7 วินาที: ไหม้ (สีดำ) ใส่จาน/ส่งเพื่อนไม่ได้ ต้องลากไปทิ้งถังขยะ
  - ตอนเครื่องครัวร้อนโผล่มาครั้งแรก การ์ดรอบจะเตือน · การ์ดจบเกมนับจำนวนที่ไหม้ (ลดเกรด)
- เครื่องครัวยังส่งข้ามจอไม่ได้ (ส่งได้แค่วัตถุดิบ)

## อัปเดต: ของบนโต๊ะมีน้ำหนัก · ส่งของถูกฝั่ง · มือถือเสถียรขึ้น
- **เครื่องครัวกับจานมีน้ำหนักแล้ว** เหมือนวัตถุดิบ: จับตรงไหนก็ลากจากตรงนั้น ปล่อยแล้วไถลต่อ ชนกันได้ (เครื่องครัวหนักสุด จานรองลงมา วัตถุดิบเบาสุด ของเบาชนของหนักจะเด้งออก)
  - จานที่เสิร์ฟ/เททิ้ง จะกลับไปที่เดิม · เครื่องครัวกับจานยังส่งข้ามจอไม่ได้
  - จุดวางเครื่องครัวเริ่มต้นอยู่ห่างขอบซ้าย-ขวา (ทางที่ของจากเพื่อนไถลเข้ามา)
- **ส่งของถูกฝั่งตามโต๊ะกลมจริง**: เพื่อนส่งไปทาง "ขวาของเขา" → ของเข้ามาทาง "ซ้ายของเรา" (และกลับกัน) ใช้ได้ทั้ง 2 คน (นั่งตรงข้ามกัน) และ 3–6 คน
- **ส่งของดูมีน้ำหนัก**: ของที่โยนลอยออกไปตามแรงที่โยน (โยนแรง = ไปเร็ว หมุนตัว) แล้วไถลเข้าจอเพื่อนที่ความสูงเดียวกัน ด้วยความเร็วตามแรงโยน ชนของบนโต๊ะเพื่อนได้ (ไม่โผล่ขึ้นมาเฉยๆ แล้ว)
- **มือถือ**: ล็อกหน้าจอไม่ให้เลื่อน/ซูม/กดค้างเปิดเมนูระหว่างเล่น · นิ้วที่สองไม่แย่งการลาก · ถ้าระบบยกเลิกการแตะ (แจ้งเตือนเด้ง ฯลฯ) ถือว่าปล่อยของ ไม่ค้าง · หมุนจอ/เปลี่ยนขนาดจอแล้วจัดโต๊ะใหม่ · ฟิสิกส์จำตำแหน่ง element ไว้ ไม่ต้องค้นหาใหม่ทุกเฟรม (ลื่นขึ้น)

## อัปเดต: จอเท่ากันทุกเครื่อง (ไม่ซูม) · มินิเกมในครัวโกลาหล
- **ห้ามซูมบนมือถือ**: ปิด pinch / double-tap zoom (รวม iPhone ที่ไม่สน user-scalable=no)
- **ครัวโกลาหลเป็น "เวที" ขนาดคงที่ 1280×720** แล้วย่อ/ขยายทั้งก้อนให้พอดีจอ: คอมกับมือถือเห็นภาพเดียวกันทุกอย่าง (ตำแหน่ง ขนาดของ การ์ด หลอด) มือถือแค่เล็กกว่า ขอบที่เหลือเติมสีโต๊ะ
  - ฟิสิกส์/การลากคิดในหน่วยของเวที จึงแรงโยนเท่ากันทุกจอ
  - กฎ CSS เดิมที่ย่อของบนจอเล็กถูกปิดในโหมดนี้ (เพื่อไม่ให้หน้าตาต่างจากคอม)
- **มินิเกมแบบโหมดอื่นมาอยู่ในครัวโกลาหลแล้ว**: วางของลงเครื่องครัว (หรือแตะเครื่องครัว) → หน้าต่างมินิเกมขึ้นกลางโต๊ะ
  - เขียง = สับให้ตรงช่อง · ครก = ตำรัว ๆ · กระทะ = ปัดผัด · หม้อทอด = จุ่ม/ยกตะแกรง · หม้อต้ม = คุมไฟ · เตาอบ · เตาถ่าน = พลิก · ซึ้ง = เติมน้ำ · ส้มตำ = ตำ/คลุก
  - ระหว่างเล่นมินิเกม โต๊ะยังเดินต่อ (ออร์เดอร์ยังนับเวลา) ต้องรีบ
- แก้บั๊ก: มินิเกมหม้อทอดใช้ id ซ้ำกับหน้าจอเกม (#fs) ทำให้หน้าเกมพัง
