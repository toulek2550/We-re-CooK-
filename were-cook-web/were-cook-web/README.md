# We're CooK? — วิธีรันและเอาขึ้นเว็บ

## โครงสร้าง
- `public/index.html` — ตัวเกมทั้งหมด (ภาพ, ล็อบบี้, ห้องรอ, ฉากโต๊ะ) ไฟล์เดียว ไม่ต้อง build
- `server.js` — เซิร์ฟเวอร์ Node.js + Socket.IO ทำหน้าที่เสิร์ฟหน้าเว็บ และส่งข้อมูลล็อบบี้/ห้องแบบเรียลไทม์
- ตัวเกมตรวจเองว่ารันอยู่ที่ไหน: ถ้าเปิดผ่านเซิร์ฟเวอร์นี้จะใช้ Socket.IO อัตโนมัติ ถ้าเปิดไฟล์ตรง ๆ จะเป็นโหมดออฟไลน์มีบอท

## รันในเครื่อง
1. ติดตั้ง Node.js 18 ขึ้นไป (nodejs.org)
2. เปิด terminal ในโฟลเดอร์นี้ แล้วสั่ง
   ```
   npm install
   npm start
   ```
3. เปิด http://localhost:3000 สองแท็บ แท็บหนึ่งสร้างห้อง อีกแท็บใส่รหัสเข้าห้อง
4. ให้เพื่อนในวง Wi-Fi เดียวกันเล่น: เปิด http://<IP เครื่องคุณ>:3000

## เอาขึ้นเว็บจริง (ฟรี) ด้วย Render
1. สร้าง repository บน GitHub แล้วอัปโหลดทั้งโฟลเดอร์นี้ขึ้นไป
2. ไปที่ render.com → New → Web Service → เลือก repo นั้น
3. ตั้งค่า
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
4. กด Deploy รอสักพักจะได้ลิงก์ เช่น `https://were-cook.onrender.com` ส่งลิงก์นี้ให้เพื่อนเล่นได้เลย

หมายเหตุ: แผนฟรีของ Render จะหลับเมื่อไม่มีคนเข้าประมาณ 15 นาที คนแรกที่เข้าอาจต้องรอ 30–60 วินาที

## ทางเลือกอื่น
- **Railway** (railway.app): New Project → Deploy from GitHub → ระบบตั้ง `npm start` ให้เอง
- **Fly.io**: เหมาะถ้าต้องการให้เซิร์ฟเวอร์ใกล้ไทย (เลือก region `sin` สิงคโปร์)
- ห้ามใช้โฮสต์แบบ static อย่างเดียว (GitHub Pages, Netlify แบบปกติ) ถ้าต้องการเล่นหลายคน เพราะต้องมีเซิร์ฟเวอร์ Socket.IO ทำงานตลอด

## ขั้นต่อไปที่ควรทำ
- ย้ายตรรกะเกม (ตรวจจาน, คะแนน) ไปไว้ที่เซิร์ฟเวอร์ หรือใช้ไฟล์ shared แบบ UMD ให้ทั้งสองฝั่งใช้ร่วมกัน เพื่อกันโกง
- เพิ่มระบบกลับเข้าห้องเมื่อเน็ตหลุด (reconnect) โดยจำรหัสห้องไว้ใน localStorage
